Add-ons bundled with Blender

  • Export Paper Model - unfold a simple (even textured) model into 2D and print it to fold together
  • Import AutoCAD DXF Format
  • Import Images as Planes - easily add images in 3D, many at once.
  • Copy Attributes Menu
  • Modifier Tools
  • Sun Position - the real sun angle and sun animation
  • Material Utilities - SHIFT+Q - a great tool for swapping materials
  • Bsurfaces GPL Edition - a modelling tool
  • F2 - a modelling tool
  • LoopTools - a modelling tool
  • tinyCad Mesh tools - great when you want to extend a line, join corners or find an intersection
  • Node Arrange - helps when working with nodes
  • Node Presets - helps when working with nodes
  • Node Wrangler - helps when working with nodes
  • Align Tools - align elements in 3D
  • Bool Tool - cut objects with objects
  • Carver - carve with a "knife"
  • Edit Linked Library - easily open linked files
  • Freestyle SVG Exporter - if you generate lines in your render, you can export them as vectors

Add-ons worth installing

  • BlenderBIM - an all-in-one for BIM data, from 3D to schedules, cost estimates and 2D documentation.
  • BlenderGIS - an all-in-one for geolocation and data import.
  • Modular Tree - free generation of amazing trees!
  • PRJ - a simple generator of drawings from a 3D model (not tested)
  • CAD Transform - move objects the way you do in Revit Tutorial video
  • CAD Sketcher - very CAD-like solid modelling with constraints.

Paid add-ons

  • https://www.scatterforblender.com/

Assets

  • Poly Haven + ADDON my first choice, everything under CC0! It lives on donations; I recommend buying the add-on to support them
  • BlendSwap - 3D models, around for a long time
  • BlenderKit + ADDON - models, textures, HDRIs
  • Sketchfab + ADDON - 3D models
  • Quixel Megascans - free only for Unreal Engine; high-quality scans and textures for $19/month. In one month you can download 45 materials or 22 3D models: decide what you need, test for free, then subscribe for one month.
  • textures.com - paid, but worth considering: high-quality textures and 3D scans
  • https://ambientcg.com/
